# Rule: Issue tracker

TODO: no issue tracker or MCP connector is wired up for this repo yet, and no ticket prefix is chosen.
Until then, work items come from the topic table in [`../ROADMAP.md`](../ROADMAP.md). The rules below
apply as soon as a tracker is connected.

## Read — allowed
- Read the ticket, its subtasks and linked issues (via the issue-tracker MCP connector) to understand
  scope before working.

## Write — never
- Never create, edit, comment on, or transition issues. When something needs to reach the tracker
  (status, reply, task list), draft the text in chat for a human to post. Ticket numbers live in the
  `docs/todo/` working doc, never inside specs.
