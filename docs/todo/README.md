# Working docs (in flight)

Living per-task docs while work is in progress: one `<TICKET>-####.md` per ticket (or one
`<short-topic-name>.md` per topic while no ticket prefix exists) with the plan, locked decisions, and a
completed-vs-pending list, so any session/teammate can continue.

- While in flight, task state lives here (the only place ticket numbers belong).
- When the work ships: fold the behaviour into the matching spec, update link maps, and move this
  doc to `archive/` (don't delete — it's attached to the ticket).
- No date prefixes on file names.
