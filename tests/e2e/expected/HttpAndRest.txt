=== 2. HTTP methods — GET, POST, PUT, DELETE; safe vs idempotent ===
Start: 3 accounts
  GET    /api/accounts/1        -> 200 OK (2xx)  {"id":1,"owner":"Asha Rao","balance":500.00}
  GET    /api/accounts/1        -> 200 OK (2xx)  {"id":1,"owner":"Asha Rao","balance":500.00}
After GET twice: 3 accounts (safe: nothing changed)
  POST   /api/accounts          -> 201 Created (2xx)  {"id":4,"owner":"Dana Ortiz","balance":100}
  POST   /api/accounts          -> 201 Created (2xx)  {"id":5,"owner":"Dana Ortiz","balance":100}
After POST twice: 5 accounts (not idempotent: two were created)
  PUT    /api/accounts/2        -> 200 OK (2xx)  {"id":2,"owner":"Ben Carter","balance":900}
  PUT    /api/accounts/2        -> 200 OK (2xx)  {"id":2,"owner":"Ben Carter","balance":900}
After PUT twice: 5 accounts (idempotent: account 2 is simply replaced)
  DELETE /api/accounts/3        -> 204 NoContent (2xx)
  DELETE /api/accounts/3        -> 404 NotFound (4xx)
After DELETE twice: 4 accounts (idempotent: account 3 is gone either way)
  DELETE /api/accounts          -> 405 MethodNotAllowed (4xx)
Allow header: GET, POST
